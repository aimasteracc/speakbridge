# 本地功能扩展

日期：2026-11-04。依据用户提供的 Speakly 更新说明独立实现；基线为 0.7.11，标签 `v0.7.11-before-workspace-features-20261104`。用户已选择先做本地功能。

## 0.8.0 实现范围

| 功能 | 实现结果 | 验证 |
| --- | --- | --- |
| 会议录屏 | 已接通屏幕／窗口选择、音画录制、会话视频标签与回看 | 合成画面和音频录制、暂停、停止、重启回看、删除 |
| 独立录屏与截图 | 已接通区域选择、可选麦克风／系统音频、MP4、本地素材历史 | 取消不录制、裁剪不越界、磁盘写入失败、导出 |
| 快捷键 | 每个动作最多 3 个绑定，支持中键及侧键，冲突提示 | 注册失败回滚、重复绑定、按住松开、鼠标不重复触发 |
| 剪贴板 | 默认关闭；文本／富文本／图片／文件格式保留，搜索与删除 | 不读初始剪贴板、限额、重启恢复、原格式复制、目标安全 |
| 会议流程 | 暂停恢复、说话人名称、结束后可选自动纪要、空闲结束设置 | 暂停不送音频、时轴、迟到结果、失败保留正文 |
| 会议提醒 | 本地检测会议应用使用麦克风，提示后由用户开始 | 不自动录音、去重、关闭开关；按平台验证 |
| 导出 | 在 TXT／Markdown／SRT 基础上添加 Word／PDF | Unicode、表格、长文、文件有效性 |
| 屏幕问答 | 本地 OCR → 确认文字 → 提问；手动保存记忆；沿用所选文字引擎，不进行图片视觉理解 | 截图内容作为数据、取消、记忆删除、不自动上传 |
| 常用语言 | 主语言及额外语言偏好，按引擎能力传递 | 输入校验、引擎参数、单语言本地模型限制明确 |
| 设置与数据 | 搜索设置、媒体／剪贴板／记忆数据管理 | 搜索命中、单独删除、全选、保留会话正文 |
| 字幕与工具栏 | 保留双语、移动、缩放；增加会议悬浮控制 | 最小尺寸、快捷键、焦点、暂停与停止同步 |
| Windows arm64 | 构建目标、原生组件与依赖兼容检查 | 构建与包内架构；实机证据不足时明确 pending |
| 更新 | 本地更新检查入口；自动安装依赖签名与正式发布渠道 | 不把未发布源码当作可自动安装版本 |

## 数据与实现约定

录屏由用户显式开始；音频是否随视频保存可选择。素材仅存本机，可独立删除。剪贴板默认关闭，启用后才收集变化。录制与快捷键状态可见，取消和失败不得显示为成功。测试使用独立数据目录、合成画面和音频，不操作现有录音或用户会议。

使用方法见[本地工作区指南](guides/local-workspace.md)，已执行与待验收场景见[验证状态](verification.md)。滚动截图需要用户缓慢滚动，程序对齐拼接；会议发言人由用户标注，不自动分离；更新只检查正式 Release，不后台安装。Windows / Intel Mac 和真实鼠标、系统音频仍需实机验收。
