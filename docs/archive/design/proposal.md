# SpeakBridge UI 改善仕様案

状態：画面案の確認待ち。実装前の基準は `42bca8a`。本書は現在のアプリの
実装済み仕様ではなく、承認後の作業範囲を定めるもの。

## 目的と優先順位

1. 録音の状態・終了操作・現在の文章をひと目で把握できる。
2. 原文と訳文、議事録の見出しと表を長時間読める。
3. 履歴の個別選択・全選択と、削除される対象を取り違えない。
4. 現在の音声入力・自動挿入・認識処理の挙動を維持する。

UI UX Pro Max の検索結果から Minimalism / Swiss Style を採用。マーケティング
ページのヒーロー構成や外部 Web フォントの推奨は、今回の作業アプリには適用しない。

## ナビゲーションとアイコン

頻繁に使うリアルタイム翻訳・音声入力・議事録・履歴を上部に集める。
辞書とショートカットは補助グループ、設定とライセンス表示は下部に置く。
ホームの既存機能は参照可能なままにし、概要画面への入口の移動として扱う。

| 操作 | Lucide アイコン |
| --- | --- |
| リアルタイム翻訳 / 録音 | `Mic` |
| 音声入力 | `AudioLines` |
| 議事録 | `ClipboardList` |
| 履歴 | `History` |
| 個人辞書 | `BookOpen` |
| ショートカット | `Keyboard` |
| 設定 | `Settings2` |
| ライセンス表示 | `FileText` |
| 字幕 | `Subtitles` |
| 停止 | `Square` |
| コピー / 保存 / 削除 | `Copy` / `ArrowDownToLine` / `Trash2` |

線幅 2px、通常サイズ 20px。文字のある操作では装飾 SVG を `aria-hidden` にする。
アイコンだけの操作には明確な名前を付ける。原版アプリ由来の画像は使用しない。
Lucide / Feather の原文表記は `licenses/` を配布対象に含めて保持する。

## リアルタイム翻訳

- 上部に状態、経過時間、字幕切替、開始／終了を集約する。録音中は終了を最優先にする。
- 音声ソース・言語・利用エンジンをコンパクトに表示。録音中に変更できない設定は
  その理由を説明し、現在値が分かる状態で無効にする。
- 原文と翻訳は同じ発話ブロックで対応させ、タイムスタンプは細い列に分離。
- 現行の確定／未確定テキストの更新と追従スクロールを維持。文章の更新でページ全体を
  再アニメーションしない。過去の文章を読んでいる間は最下部へ強制移動しない。
- 右側はセッション情報と終了後の操作。録音中の議事録作成・書き出しは無効にする。
  保存は既存の自動保存を維持し、「自動保存されます／保存済み」と状態で表示する。
- 外部送信の文言は実際に選択したエンジンに応じて変える。CLI の使用だけを理由に
  ローカル処理と表示しない。API や Harness 等が外部に送る場合は送信対象を明示する。
  画面案の「音声：ローカル／翻訳：DeepSeek」は一つの設定例。

## 議事録と履歴

- 文書を大きなペインで表示し、一覧と本文を往復しやすくする。原文と議事録のタブ、
  コピー、Markdown 保存、再生成を上部にまとめる。
- 作成の入口は既存セッションの選択と生成につなぐ。外部資料インポート機能の追加は
  今回の UI 整理だけで実装済みとみなさない。
- 既存の7節の日本語プロンプト、資料種別と範囲に応じた末尾メモ、推測しないルールを維持。
  日時・担当・期限の「不明／未定」と状態「未着手」を正しく読める表にする。
- Markdown は既存の `react-markdown` + `remark-gfm` を利用。生 HTML・画像取得・
  リンク遷移の制限を維持し、装飾変更のために緩めない。再生成失敗時は元の議事録を残す。
- 一覧に各行チェックボックス、全選択、選択件数を常設する。検索中は
  「検索結果をすべて選択」と表示。進行中のセッションは選択対象外。
- 議事録画面の削除は「選択した議事録を削除」。転写・翻訳は残ることを確認文に明記。
  履歴画面は「選択したセッションを削除」とし、関連する転写・翻訳・議事録も削除される
  ことを明記する。既存の個別削除・確認フロー・一括処理を維持。
- 空の一覧、検索結果0件、生成中、失敗、選択なし、複数選択の状態も実装対象。

## アクセシビリティと動き

- フォーカス枠は 2px 以上。Tab 順を見た目と一致させ、ダイアログは Esc、フォーカス
  閉じ込め、閉じた後の呼び出し元への復帰を保証する。
- 選択状態・録音状態は色と文字の両方で示す。全選択には一部選択状態も表示する。
- `prefers-reduced-motion` を尊重。通常の hover は約120ms、遷移は約160msを目安にし、
  処理やキー入力をアニメーションの終了待ちにしない。
- ライブ文章を一文字ごとに読み上げさせない。状態の変化だけ適切な live region で通知する。
- 100% / 150% / 200% の表示で長い日本語・中国語、長い表セルが操作を隠さないことを確認。

## 承認後の確認シナリオ

1. マイク許可なし／接続中／録音中／停止処理中の表示と操作可能性を確認する。
2. 発話の途中修正、無音、連続する句読点、スクロール中の更新を固定フィクスチャで検証する。
3. 音声入力の既存ショートカット、対象アプリへの挿入、終了・取消を回帰確認する。
4. 部分資料の議事録、表、長いセル、コード、HTML・画像入力、生成失敗を検証する。
5. 履歴の個別／全選択、検索で絞った範囲、進行中の除外、議事録だけの削除を確認する。
6. 実装後に両 OS 向けパッケージ内の Lucide / Feather 原文表記を検査する。
7. ネットワークやデータ移行を伴わない UI 回帰を先に確認し、実際の会議データを
   スクリーンショットや生成画像の入力に使わない。

## 画面案の扱い

完成イメージは画像生成によるレビュー資料。細部の文字や寸法は本書を優先し、
生成画像をそのまま背景やアイコン素材としてアプリに組み込まない。
画像への OK 後に実装を開始するという、ユーザー指定の手順に従う。
