## スキルの確認

UI UX Pro Max は既に導入されていた。上書きせず、73ファイルの Git blob
ハッシュを公式リポジトリのコミット
`3a13158ff1f32156cbe144108de48eda2ecaed9a` と照合し、全件一致を確認。

[公式ソース](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill/tree/3a13158ff1f32156cbe144108de48eda2ecaed9a)
／ [MIT ライセンス原文](UI-UX-Pro-Max-LICENSE.txt)

検索 `transcription meeting desktop workspace` は Voice Recorder & Memo と
Minimalism & Swiss Style に一致。高コントラスト、明確な文字階層、控えめな
装飾を採用する。検索結果のランディングページ構成はデスクトップの作業画面に
適合しないため採用しない。Poppins / Open Sans の外部読み込みも採用せず、
日本語・中国語を表示できる OS 標準書体を使う。

アイコンの検索結果からは、説明ラベルと装飾アイコンの役割分離、同一画面での
系統統一を採用。ライブラリの切替は必須ではなく、既存 Lucide の利用条件を
確認して継続する。React の検索結果からはダイアログのフォーカス管理を採用。

## 素材の判断

| 対象 | 確認結果 | 対応 |
| --- | --- | --- |
| ナビゲーション・操作アイコン | Lucide React 0.468.0。ISC、一部 Feather 由来は MIT | 同一系統・2px 線幅に統一。両ライセンス原文を同梱対象にする |
| アプリ・トレイ画像 | SVG ソースと PNG 生成スクリプトが存在。トレイとアプリ PNG は一致 | 元画像を Git に保存。商標・独占性まで確認したとは扱わない |
| 原版アプリの画像 | 現在の UI 素材一覧で使用を確認していない | スクリーンショットからの切り出し・ブランドロゴの再利用はしない |
| フォント | プロジェクト内にフォントファイルなし。CSS の書体指定のみ | OS にある書体で描画。将来同梱する場合は個別にライセンス確認 |
| 完成イメージ | imagegen によるオリジナルの画面案、固定サンプル文のみ | 画面配置の確認用。画像内のアイコンを製品素材として切り出さない |

詳細なアイコン名と検証値は [asset-inventory.json](asset-inventory.json)、
配布用表記は [THIRD_PARTY_NOTICES.md](../../../THIRD_PARTY_NOTICES.md) を参照。
既存配布物の Lucide ライセンスは確認できたが、Feather の MIT 原文も確実に
含めるため、独立した同梱用ファイルを用意する。包括的な法的適合性や商標の
権利調査を保証するものではなく、今回の確認範囲は UI 素材とその出典・表記。

確認までは、動作中アプリの UI・ショートカット・認識エンジンを変更しない。

`licenses/**/*` を追加し、`scripts/verify-package.cjs` で配布物の原文とソースの
一致を確認する。今回追加した文書が、既存の 0.7.8 配布物にも入ったとは扱わない。
