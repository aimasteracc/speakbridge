# 0.7.0 操作改造

日期：2026-11-02。0.7.1 更新：Mac 新配置默认键改为右 Option，Fn 仍可自行选择；未授权时不再显示按住模式已就绪，权限检查增加输入组件刷新。以下 0.7.0 的默认 Fn 描述为历史行为。

目标：把原先需要回到主窗口、按两次固定组合键的跨应用听写，改成可在目标输入框中完成的按住说话流程。

## 对照原版的证据

复用了既有 REA 分析记录，没有重新执行原版、读取账户凭据或观测原版会议。原始 ASAR SHA-256 为 `fa341adaa9dfc5102d3bc3a950c06034a7c353548f6d833434d403011009e885`，父证据 `ev_655e9d1830f94fa678c517ed2fd9b637ba15a8270afa13324bc24c4227dd122a`。保存的 `test-artifacts/original-analysis/source/dist/src/services/VoiceRecognitionService.js:1556` 至相邻方法记录按下／松开时间、窗口显示时间、误触标记。这支持客户端区分按键阶段的静态判断，不能证明原版具体的防误触阈值、悬浮窗尺寸或延迟。

本次独立实现的设计选择：440 × 132 悬浮提示、成功后约 1.4 秒隐藏、按键可选列表、保留已有 Cmd/Ctrl + Shift + D。原版公开帮助称免持模式初始未分配快捷键；我们保留旧键以兼容已有用法。没有复制原版品牌、服务器接口或受保护素材，也没有声称逐像素相同或同速。

## 使用

1. 在「语音输入」点击「准备开始」。允许麦克风，Mac 按提示到辅助功能中允许声桥，再回到应用检查。缺模型时进入语音模型设置下载。
2. 回到目标软件，点一下普通文本输入框，按住 fn / 🌐（Mac）或右 Alt（Windows）说话，松开即停止采集，等待定稿后输入。准备阶段有明确提示；第一次系统授权完成前请等麦克风就绪。
3. 长段口述可用 Cmd/Ctrl + Shift + D，或在「快捷键」选择其他免持键。按住模式与免持模式可独立关闭。Windows AltGr 键盘使用者可把按住模式改为右 Ctrl。
4. Esc 或悬浮窗 × 取消；方形按钮结束并输入。成功后提示自动收起，结果仍能在「语音输入」中复制。失败时提示保留，不自动重试。
5. 关闭主窗口后仍可语音输入；菜单栏／托盘可以重新打开或退出。普通会议模式关窗会停止并保存，避免隐藏录音；只有带独立录音提示的听写继续在后台。

Mac 检测到已知的原版 Speakly 安装正在运行时，会让出 Fn 并提示换键；也会在 Fn 按下时重新检查，避免两个应用争抢。这只覆盖已验证的原版 bundle 标识，不能保证检测所有第三方快捷键工具。

选中的按住键会被保留给声桥，原有同键行为（如 Fn 导航组合或 Windows AltGr）可能受影响，可换键或关闭。密码框和不兼容控件仍不会自动输入。识别或注入期间切换输入框会保留结果供复制；已发送的文字无法撤回，取消或失败时应检查是否有部分输入。

## 实现与数据边界

原生组件持续运行，独立事件循环监听选定按键的按下／松开，不收集其他键值或目标正文。JSON 行协议区分请求回复与按键事件；clear 仅清除目标，保留监听。Mac 用 CGEvent tap，Windows 用低层键盘 hook；输入保留 AX/UIA 焦点和选区检查，不按回车。0.7.3 起 Mac 改用正常粘贴，临时剪贴板限定本机并恢复原内容；Windows 仍使用 Unicode 事件。

启动期间已采集的 PCM 仅在渲染进程内存队列暂存，最多 30 秒；模型就绪后先按顺序送入 ASR，再结束定稿。松开时先停止麦克风；模型未就绪也不会继续采集。取消、渲染进程退出和应用退出都有主进程兜底，取消后不自动输入。

听写仍强制本地模型、仅麦克风、关闭翻译、无听写历史／原始音频落盘，不调用 API 或文字大模型。准备按钮只预载已下载模型，不自动下载或调用云服务。原有会议引擎、API 凭据与会话历史不迁移。新的快捷键配置单独保存在 `dictation-settings.json`。
