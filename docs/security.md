# 数据与隐私

[返回文档索引](README.md)

本页说明声桥代码的数据处理边界，不替代服务商条款或公司的会议资料使用要求。没有把“使用 API”一概等同于用于训练，也没有把“不用于训练”一概等同于不保留日志。采用云服务前，需要按实际服务、账户和合同确认。

## 数据会发往哪里

| 功能与引擎 | 处理位置与发送内容 |
| --- | --- |
| 本地语音模型，包括增强识别 | 音频在本机推理；首次下载模型需要网络，模型不内置在安装包 |
| OpenAI 兼容 API 语音 | 音频及识别提示发送到配置的语音服务 |
| Soniox | 连续音频和识别提示发送到固定的官方端点，包括停顿音频 |
| API 翻译／纪要 | 相应转写资料和提示发送到所配置文字服务；Responses 请求带 `store: false` |
| Codex / Claude Code / DeepSeek Harness | 文字资料交给所选 CLI 和配置的模型服务；通常是云端并使用账户额度 |
| 本机 Ollama | 文字发送到配置的本机环回服务；只有已下载且本地推理的模型才构成离线路径 |
| 自定义 Harness | 文字交给配置的可执行程序；它的工具、网络和日志行为须由适配器约束 |
| 听写原文直出 | 只用本地 ASR；结果通过原生输入组件交给目标输入框 |
| 屏幕文字问答 | 截图先本地 OCR；用户确认后将文字、问题及勾选的记忆交给所选文字引擎，不发送图片 |
| 可选听写整理 | 发送定稿转写和词典到明确选择的文字引擎；不发送原始音频或目标输入框正文 |

语音、会议文字和听写整理是独立配置。仅选择本地语音，不能保证纪要和翻译也离线；需要完全本地处理时，应明确选择本地 ASR、实际本地 Ollama 模型或关闭文字处理，并检查听写整理选择。具体配置见[引擎指南](guides/engines.md)。

`store: false` 仅是接口请求参数，不是对服务商所有日志、审计、滥用监测或保留策略的保证。本项目没有遥测。剪贴板历史和会议麦克风状态提醒均默认关闭；仅在启用后本地监控。检查更新由用户手动发起，只访问项目的公开 GitHub Release，不自动安装。

## 本地文件与临时数据

设置页显示实际应用数据目录。Mac 通常在 `~/Library/Application Support/SpeakBridge`，Windows 通常在 `%APPDATA%/SpeakBridge`；开发或隔离测试可以使用不同目录。

| 数据 | 存储方式 |
| --- | --- |
| `sessions.json` | 明文会话转写、翻译、纪要及生成错误；不是加密会议库 |
| `settings.json` | 模型、服务地址、词典及常规偏好；不包含明文 API Key |
| `credential.json` / `soniox-credential.json` | 使用 Electron safeStorage 的系统加密结果；系统加密不可用时拒绝保存新密钥 |
| `dictation-settings.json` | 听写快捷键和整理选择，默认整理关闭 |
| `shortcuts.json` | 每个功能最多三个键盘／鼠标绑定 |
| `media.json` / `media/` | 明文视频、图片及索引；选择录音时，音频随视频保存在本机 |
| `clipboard.json` / `clipboard/` | 启用后保存的明文剪贴板格式与预览；默认关闭，不导入启用前内容 |
| `screen-questions.json` / `screen-memory.json` | 明文问答与手动保存的长期记忆，可分别清理 |
| `ocr-models/` | 本地 OCR 模型缓存，首次提取需要下载，不上传截图 |
| 配色偏好 | 应用自己的 localStorage，键名 `speakbridge.appearance.v1` |
| 模型缓存 | 本机下载的模型文件，模式间复用 |
| 原始音频、当前听写原文与整理结果 | 应用内存中暂存，不写入会话历史；未开启录屏音轨时原始音频不落盘；选择录音后随视频保存 |

启动时只读取密钥是否已配置的元数据；需要调用或保存 API 时才使用加密存储。已保存的密钥不会从主进程回传给渲染器。

内置文字 CLI 使用临时工作目录。DeepSeek Harness 会读取已有配置与凭据，并生成权限受限的临时配置；正常收尾时删除临时会话。因此“原始音频不落盘”不代表任何文字处理都不产生临时文件。自定义适配器及目标应用可能有独立的日志、历史和同步行为。

Mac 自动输入会临时设置本机剪贴板并在事务结束后恢复；用户期间复制的新内容优先保留。主动点复制会覆盖剪贴板。输入到其他应用后，声桥不能撤回它们的草稿、同步或服务端记录。

删除声桥历史仅影响应用本地记录，不删除已导出的文件、备份或外部服务中的数据。录屏、剪贴板和问答的操作范围见[本地工作空间](guides/local-workspace.md)。会议删除范围见[记录管理](guides/meeting-notes.md#历史记录与删除范围)。

## 源码与分享

提交或分享前执行：

```sh
npm run check:sensitive
git diff --check
git status --short
```

扫描器只输出位置和类别，不输出疑似凭据内容；它检查常见格式，不能证明不存在任意秘密。不要把真实会议、录音、账户配置、模型认证信息或个人路径写入代码、文档、样例和截图。新建私有仓库也不能替代此要求。

`.gitignore` 排除依赖、构建包、本机测试产物、凭据和常见个人配置。源码分享同样应排除 `node_modules/`、`dist/`、`release/` 和 `test-artifacts/`。忽略规则不会自动清除已经提交过的数据；需要核对 Git 历史和实际暂存内容。
