# 开始使用

[返回文档索引](../README.md)

## 获取与运行

声桥面向 **macOS 13+（Apple Silicon / Intel）** 与 **Windows 10 / 11 x64**。macOS 系统音频采集建议使用 14.2+。平台运行证据见[验证状态](../verification.md)，不能仅凭构建成功判断设备兼容性。

截至 2026-11-03，GitHub 仓库提供源码，尚未发布 GitHub Release 或安装包下载。开发者从源码运行请按[开发指南](../development.md)准备依赖。开发机上已有的 `release/0.7.11/` 是本机验证产物，不随克隆下载。

拿到对应架构的包后：

- Mac：解压并将 `SpeakBridge.app` 放到“应用程序”，打开应用。现有包为 ad-hoc 本地签名，未做 Apple 公证；不要把它视为已具备公开分发签名的正式版本。
- Windows：解压整个目录再运行 `SpeakBridge.exe`，保留同目录依赖。使用 NSIS 安装包时按向导安装。
- 更新前结束并保存正在进行的录音。换包或移动应用后，Mac 可能需要重新授予输入权限。

## 第一次录制会议

1. 可先点“先体验演示”查看固定中日双语文本。演示不会录音或调用 API。
2. 在“设置”中分别选择语音转写、翻译与纪要引擎。使用 DeepSeek 时请直接按[DeepSeek 配置步骤](engines.md#deepseek-api)操作。
3. 本地识别需先下载选中的语音模型。只需要转写时，可以把翻译目标设为“关闭翻译”。
4. 保存设置后，按需要点“保存并测试连接”。云端测试使用固定短文本或测试音频，可能消耗少量额度。
5. 在实时翻译页选择麦克风、系统音频或二者混合；选择源语言及翻译目标，开始会话，并按系统提示授权。
6. 结束后等待定稿与保存，再到历史中复制、导出或[生成会议纪要](meeting-notes.md)。

源语言明确时可直接选择中文、日文或英文；混合语言可以先用自动识别。识别质量受音频、模型和语言设置影响，界面中的流式动画不等于模型本身是原生流式识别。

## 权限与录音

| 用途 | 需要准备什么 |
| --- | --- |
| 麦克风会议 / 听写 | 允许应用使用麦克风；Windows 需允许桌面应用访问麦克风 |
| Mac 系统音频 | 在系统提示中允许系统音频录制，或在共享选择器中共享音频 |
| Mac 自动向其他应用输入 | 额外授予辅助功能权限，见[跨应用听写](dictation.md) |

取消共享、没有选中音频或音频轨道已结束，均不能当作成功录音。系统音频的屏幕轨道只用于建立采集，不显示、保存或发往服务。扬声器可能让麦克风重复录到系统声音，同时采集时宜使用耳机。

开发模式的系统权限可能归属终端或 IDE；真实权限验收应使用打包应用。音频设备断开或连接失败会停止并保留已收到的文本，不会悄悄切换服务继续计费。

## 日常入口

| 功能 | 操作 |
| --- | --- |
| 会议开始 / 结束 | 页面按钮或 `Cmd/Ctrl + Shift + Space` |
| 字幕显示 / 隐藏 | 字幕入口或 `Cmd/Ctrl + Shift + L`；字幕窗口可拖动和调整大小 |
| 给其他应用输入 | [跨应用听写](dictation.md)，免持快捷键默认 `Cmd/Ctrl + Shift + D` |
| 改配色 | 左下“外观与配色”：雾白、暖砂、松绿、海蓝、深夜或跟随系统；选择后自动保存 |
| 记录删除与全选 | [会议纪要与记录管理](meeting-notes.md#历史记录与删除范围) |

这些是默认值，已保存的个人快捷键不会被文档或升级强制覆盖。关闭主窗口后听写功能可留在菜单栏／托盘，完全退出请使用退出菜单；普通会议关窗会结束并保存。

数据去向和费用见[数据与隐私](../security.md)，常见问题见[故障排查](troubleshooting.md)。
