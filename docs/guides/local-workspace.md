# 录屏、剪贴板与本地工作空间

[返回文档索引](../README.md)

适用源码版本：0.8.0。账号、二维码登录、跨设备同步、上传和分享链接留待后续；目前没有接入 Speakly／Genspark 的账号或服务。

## 会议画面与独立录屏

会议开始后，点「画面录制」，选择全屏或窗口，预览后开始。音频可选择不录音或使用当前会议音频。暂停会议会同时暂停音画录制；停止会议会先保存视频，再结束转写。会话列表显示「有视频」，详情里的「视频」标签可播放。

独立录制从「录屏与截图」进入，或使用默认 `Cmd/Ctrl + Shift + R`。可选麦克风、系统音频、二者混合或不录音。视频为 MP4（H.264／AAC，音轨按选择），分块写入本地磁盘，不把整场会议积压在内存。单段上限 10 GB；编码、权限或写盘失败会提示，不把未完成文件显示为成功视频。

预览中勾选「只录制指定范围」可拖出选区，也可输入百分比。相同选区用于截图。窗口最小化、受保护内容、系统权限和平台采集限制可能造成空画面；先检查预览。软件不保证可录制所有应用或受保护视频。

「显示快捷键提示」默认关闭，只在画面中显示导航键和修饰键提示，不显示普通输入文字；需要原生快捷键权限。提示不会单独写入按键日志。

录制时有可移动的置顶控制条，可暂停、恢复、停止；主窗口关闭后独立录屏仍继续，完全退出时会等待保存。系统休眠或渲染进程崩溃会中断；未完成 `.part` 文件保留在本机，并可在数据管理中清理，它们不保证可恢复播放。

## 滚动长截图

选择窗口及正文范围，音频设为「不录音」，预览后点「滚动长截图」。你在目标窗口缓慢向下滚动，程序每 1.2 秒比较画面并拼接重叠部分；结束后用悬浮控制条或主窗口停止保存。

这是用户滚动、自动对齐的方式，不会擅自控制其他应用滚轮。尽量排除固定工具栏、动画和视频，一次滚动不超过画面高度的 85%。无法对齐时提示并保留已拼接部分。输出宽度最多 1920 px，高度最多 16384 px，像素总量最多 2400 万。

素材历史支持搜索、逐条删除、全选／多选删除、导出和复制。复制视频保留文件形式；目标应用必须支持粘贴附件。删除会话后其视频仍保留在独立素材历史；删除视频不会删除会话文字。

## 多快捷键与鼠标

在「快捷键」中，每个动作最多三个绑定。免持听写、会议、字幕、录屏、剪贴板可使用组合键、功能键或鼠标中键／后退键／前进键；按住说话可使用独立修饰键或鼠标按钮。

- 添加键盘绑定时点输入框并按下组合键，或在选择框中选鼠标按钮。
- 同一键不能重复分配；已被占用时提示，修改失败恢复旧绑定。
- 按住说话可同时按多个绑定，松开最后一个后结束。
- 分配鼠标按钮后，它的原用途会被拦截；删除绑定即可恢复。
- 保留旧版个人设置进行首次迁移；Fn、右 Option／Alt 等仍可能与系统或输入法冲突。

默认快捷键：免持听写 `Cmd/Ctrl + Shift + D`，会议 `Cmd/Ctrl + Shift + Space`，字幕 `Cmd/Ctrl + Shift + L`，录屏 `Cmd/Ctrl + Shift + R`，剪贴板 `Cmd/Ctrl + Shift + V`。可全部删除关闭。

## 剪贴板历史

「剪贴板」中的开关默认关闭，开启时不会导入此前的剪贴板。启用后监听新的复制变化，保留文本、HTML／RTF、图片、文件及系统提供的原格式。识别到应用标注的私密或临时类型会跳过，但无法识别所有密码或敏感信息；会议敏感场景应关闭采集。

最多 200 项、总计 128 MB，单项超过 16 MB 跳过；旧记录超额时淘汰。历史在本机明文保存。关闭采集不会清空已有历史，可逐条／全选删除；这不会删除源文件或清空当前系统剪贴板。

先点击目标输入框，再用剪贴板快捷键打开历史，选择「粘贴回原输入框」。目标仅保留 60 秒，必须仍可编辑且非密码框；失效时保留复制内容供手动粘贴，不自动按回车。自动粘贴受目标应用和系统权限限制；文件管理器等非文本目标可使用「复制原格式」后手动粘贴。

## 屏幕文字问答与记忆

1. 从「屏幕问答」截取画面，或选择已有本地截图；也可直接粘贴文字。
2. 选择英／中／日 OCR 语言并「在本地提取文字」。首次从 Tesseract 模型站点下载语言数据，以后使用缓存；截图不上传。
3. 检查、修改、删去不想发送的文字，填写问题。
4. 点击提问后，只有文字、问题和明确勾选的记忆交给已配置的文字引擎。API／CLI 可能联网并收费；本机 Ollama 可离线。

这是基于文字的问答，不具备视觉模型理解图表和图片的能力。识别错误需先修正。长期记忆只有手动添加才保存，不从回答自动学习；记忆、问答和截图可分别删除。取消任务后，迟到回答不再保存。

## 会议自动化、语言和导出

「设置 → 会议自动化」可启用结束后自动纪要、选择中日英或跟随原文、连续静音 5／10／15／30 分钟后结束。默认均关闭；暂停不计入静音。静音判断来自所选音轨，不是会议软件的结束信号。

可选会议提醒在本机检查常见会议软件／浏览器是否使用麦克风，提示后由你决定是否开始；不自动录音。Mac 依赖 Core Audio 的进程查询能力，旧系统无法提供时可手动开始。浏览器使用麦克风也可能是其他用途。

会话结束后在「转写与翻译」勾选发言人编辑，逐段标注姓名。当前本地语音模型不自动区分说话人；姓名进入后续纪要与导出，已有纪要需重新生成。

「说话语言」可设主语言和最多五个额外偏好。语言列表扩展到 Whisper 的语言代码，但每种模型的支持范围不同：SenseVoice／增强模式受其五种语言限制，Qwen3-ASR 按其支持列表校验，Whisper Base 不支持粤语代码。额外偏好只传给支持语言提示的 API 引擎，不声称能让所有模型准确识别所有语言。

导出新增 Word `.docx` 与 PDF：有纪要时导出排版后的纪要，没有纪要时导出转写；保留标题、列表和表格。TXT／Markdown／SRT 保持原有行为。

## 数据与更新

设置支持关键词搜索；「数据管理」分别清理会议、素材、剪贴板、问答、记忆、未完成录制和 OCR 缓存，服务设置及密钥保留。已导出文件不随历史删除。

「检查公开版本」只查询项目 GitHub Release，不发送本地资料。尚未启用自动安装更新；公开分发签名、公证和更新渠道需后续准备。

各平台实机验收、自动化测试和限制统一见[验证状态](../verification.md)。
