# 跨应用听写

[返回文档索引](../README.md)

## 把说话内容填入输入框

1. 在设置中下载并保存本地语音模型，打开“语音输入”，点“准备开始”完成麦克风、模型、输入权限和快捷键检查。
2. Mac 需要麦克风及辅助功能权限。辅助功能用于快捷键监听与定位／写入目标输入框；授权后回到声桥重新检查。
3. 切回目标应用，点击普通可编辑输入框，保持光标位置。
4. 按 `Cmd/Ctrl + Shift + D` 开始说话，再按一次结束。也可以使用已配置的按住说话键。
5. 等待本地定稿及可选文字整理，完成后检查目标输入框。应用不会自动按回车发送消息。

识别预览在非激活悬浮条中显示，可以随上下文修订；不会逐字写入目标输入框。最终结果只交付一次。单次听写最多 2 分钟，达到上限会收尾。开始录音和定位目标并行进行；定位失败时保留文字，不猜测输入目标。

## 快捷键与窗口

| 模式 | 默认操作 |
| --- | --- |
| 免持听写 | `Cmd/Ctrl + Shift + D`：开始一次、结束一次 |
| 按住说话 | Mac 右 Option，Windows 右 Alt；按下开始，松开定稿 |
| 取消 | `Esc`，或悬浮条中的取消按钮；原生写入已开始时按既有输入事务收尾 |

没有右侧修饰键的键盘可以关闭按住模式，使用免持快捷键。Fn 可能与输入法、表情或系统听写冲突，不能因为旧版文档写过 Fn 就认为它是当前默认值。快捷键页可以更改或独立关闭两种模式；已有个人配置会保留。

主窗口关闭后可通过菜单栏／托盘继续听写，退出应用后快捷键失效。快捷键占用、权限未生效时，请先解决页面显示的问题，不要仅凭某个快捷键注册成功就判断所有模式就绪。

## 原文直出与可选整理

“语音输入 → 听写输出”默认是**原文直出**，不会调用文字模型。明确选择 Ollama、API、Codex、Claude Code、DeepSeek Harness 或自定义 Harness 后，才在本次 ASR 全部定稿且目标定位成功后尝试整理。

整理用于去除口头禅、意外重复及明确的自我纠正，提示词要求保留语言、专名、数字、否定和不确定语气。最长等待 15 秒，可取消。程序检查部分异常输出，但不能证明每次改写语义正确；原文与整理结果可分别查看和复制。

听写语音始终在本机识别。联网整理会发送转写与词典，增加等待并使用对应服务额度；不会发送原始音频或目标输入框正文。连接参数见[引擎配置](engines.md)，实际验证范围见[验证状态](../verification.md)。

## 输入失败后的恢复

- **整理失败或输出检查未通过**：不自动输入；保留原文，检查后复制或明确重新选择输入框补填。
- **确认零写入**：可用“选择输入框并填入”，点回目标输入框，再在悬浮条点“填入”。补填复用已经展示的结果，不再次调用模型。
- **可能已写入或部分写入**：先检查目标内容，不能直接重复整段发送。界面会保留文字供核对。
- **识别未完整结束、目标不明确、密码框或不支持的控件**：不强行注入文字，可手动复制到合适的位置。

“测试自动输入（不录音）”可用固定文字先验证目标应用，不调用语音模型、API 或麦克风。输入问题与识别准确率是两条不同链路，应分别检查。

Mac 使用临时本机剪贴板执行正常粘贴，完成后恢复原有数据和格式；若期间复制了新内容，则保留新内容。Windows 使用 Unicode 输入，不向更高权限窗口提权写入。主动点“复制”会替换剪贴板。声桥不能控制目标应用或第三方剪贴板工具后续的同步行为。

听写的原文、整理结果和音频不写入会话历史，当前文本只在本次内存状态保留。清除结果不会撤回已经填进其他应用的内容。完整存储边界见[数据与隐私](../security.md)。
