# 会议纪要与记录管理

[返回文档索引](../README.md)

## 生成纪要

1. 结束会话并等待转写保存。
2. 在历史详情或会议纪要页选中该会话，确认原始转写内容。
3. 选择自动语言，或明确选择中文、日文、英文，再生成纪要。文字引擎的连接设置见[引擎配置](engines.md)。
4. 生成中查看等待时间、接收字数和分段进度；需要时停止。关闭详情不会停止任务。
5. 完成后阅读排版后的 Markdown；复制或导出保留 Markdown 原文。

自动语言依据**转写原文**的字符特征，与界面语言及翻译目标分开。中文资料生成中文、日文资料生成日文、英文资料生成英文；混合语言、只有汉字的日文或很短的资料可能需要手动指定。

当前输入来自已保存的会话转写，不是任意文件导入。程序不把自动标题和应用记录时间当作会议事实交给模型。

## 内容结构与显示

模板统一为七部分：会议概要、议程、讨论内容、决定事项、行动项、后续待讨论事项、会议定位／总结，并附资料来源与完整性说明。对应语言保留相同结构，概要、决定事项和行动项使用 Markdown 表格。

提示词要求：

- 保留专名、产品名、人员名和缩写；只有资料明确时才归属发言人。
- 不把提议或未决内容写成决定；缺失的日期、负责人和期限写“未知／待定”或对应语言表述。
- 行动项为具体任务，状态统一为“未着手”或对应语言表述。
- 按输入资料类型和是否部分资料调整末尾说明，不声称覆盖没有提供的内容。
- 对疑似误转写和不明发言人不作无根据断定；资料中的指令作为被引用内容处理。

这些是生成约束，不保证模型完全遵守，使用前仍需核对。程序用 `react-markdown` 与 GFM 显示标题、表格、列表和代码；表格可横向滚动。原始 HTML 不执行，图片仅显示替代文字，链接显示文字且不在应用内跳转。

## 长会议与模型容量

没有统一的字数截断上限。程序根据所选模型的上下文、输出预算与提示词开销估算可容纳的输入；能容纳时发送完整转写，超过预算时分段整理再汇总。每段失败都会停止，不静默跳过尾段；分段总结本身仍可能压缩细节。

以下是 **0.7.11 代码注册表**的容量，核对日期为 2026-11-03，具体部署以服务端为准：

| 模型匹配 | 上下文 token | 最大输出 token | 自动纪要输出预算 |
| --- | ---: | ---: | ---: |
| `deepseek-flash` / `deepseek-v4-pro` / `deepseek-v4-flash` 系列 | 1,000,000 | 384,000 | 通常 32,768 |
| `gpt-4.1` / mini / nano 系列 | 1,047,576 | 32,768 | 通常 32,768 |
| 未知模型或本地部署 | 不虚构，允许手动填写 | 由部署决定 | 通常 16,384 |

容量实现的权威位置是 [notes-models.cjs](../../electron/notes-models.cjs)。上下文不是可全部用于原文的空间：程序还预留输出、提示词和 5% 余量。token 只是规划估算，不是模型 tokenizer 的精确计数。

设置中可填写上下文容量、纪要输出预算和超时；容量及输出填 0 表示自动，默认单次请求超时 600 秒，可配置为 30–1800 秒。手动缩小上下文时，自动输出预算也会相应缩小。DeepSeek 官方端点的纪要请求关闭思考模式；它不代表请求会即时完成。

自动预算下发生输出截断且模型仍有空间时，程序会提高预算重试一次；不会擅自提高用户手动指定的输出预算。未知模型的容量最终由服务端判定，必要时填入实际部署参数。

## 失败、取消与重新生成

完整成功后才保存新纪要。空输出、明确截断、断流、取消或其他错误不会覆盖旧纪要；错误信息保留在记录中供重开后查看。重新生成前确认覆盖范围，旧正文保留到成功时。

HTTP 500 / 503 / 429 最多自动重试两次，通常等待 2 秒和 5 秒，并参考 `Retry-After`，单次等待最多 60 秒。身份、余额或网络断流错误不会无限重复提交。取消和删除后的迟到结果不能恢复旧任务或已删除内容。错误处理步骤见[故障排查](troubleshooting.md)。

## 历史记录与删除范围

| 入口 | 删除什么 | 保留什么 |
| --- | --- | --- |
| 首页、实时翻译或会话历史中的删除 | 该会话、转写、翻译和纪要 | 其他会话 |
| 会议纪要页或详情纪要标签中的删除 | 选中的纪要 | 对应会话转写和翻译 |
| 语音输入页清除结果 | 当前已结束听写的内存结果 | 已输入其他应用的文字及系统剪贴板 |

会话历史与会议纪要列表均支持逐条删除、勾选多条、全选、取消选择和删除所选。全选范围是**当前搜索／收藏筛选结果中可删除的记录**；切换筛选会清空旧选择。进行中的会话不可删除，没有纪要的行不能当作纪要删除对象。

确认框显示条数和范围；改变选择后需要重新确认。任一所选 ID 已失效、正在进行或写盘失败时，整批保留。应用删除不会移除已导出的外部文件。

历史支持搜索、重命名、收藏、复制，以及 TXT、Markdown、双语 SRT 导出。SRT 时间是客户端分段的近似时间，不是词级对齐。
