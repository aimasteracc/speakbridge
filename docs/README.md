## 历史材料

[历史归档](archive/README.md)保留语音模型评测、REA 调查、各版验收记录和 UI 设计案。它们用于追溯依据，不作为当前操作指南。设计概念图不代表已实现的界面；旧版的快捷键、输出预算和服务错误也不代表现在的默认值或运行状态。

## 文档维护约定

- 当前行为写入对应指南；测试证据和待验收项写入 `verification.md`。README 只保留概要和入口。
- 配置字段、命令和默认值以源码为准；新增功能时同步使用指南和验证边界。
- 历史报告保留日期和原结论，只修正导航或补充明确的历史标记。新版本不要继续把旧报告当现行说明。
- 文档链接使用仓库内相对路径。移动文件时同时检查 Markdown、脚本帮助文字和素材引用。
- 测试产物、真实会议、API Key、个人路径和本机配置不纳入文档。示例使用合成文本。
- 文档改动检查本地链接、目录覆盖、`npm run check:sensitive` 和 `git diff --check`；是否重跑产品测试由实际代码变更决定。
